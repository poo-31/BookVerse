📚 BookVerse Analytics Dashboard

An interactive book analytics dashboard built using **Python, Streamlit, Pandas, and Plotly**.

Features
- Book ratings and genre analysis
- Interactive charts and publication trends
- Search, filter, and sort books
- CSV upload and export
- Basic genre-based book recommendations

Technologies
Python • Streamlit • Pandas • Plotly

Run Locally
bash
pip install -r requirements.txt
streamlit run app.py

Future Improvements
Excel data analysis, PostgreSQL queries, and Power BI visualizations.
